# ZMODEM双向传输修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复 v0.30.29 Windows x64 SSH 会话中的 ZMODEM 下载与上传，并发布 `OpenFinalShell v0.30.29`。

**Architecture:** 主进程在 SSH 原始字节层使用每会话 ZMODEM Sentry；将普通字节交回现有终端队列，将文件内容在主进程流式读写。release workflow 对精确 tag `v0.30.29` 采用 x64 Windows 单架构路径。

**Tech Stack:** Electron、TypeScript、ssh2、zmodem.js 0.1.10、Node.js stream、Vitest、electron-builder、GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-09-19-zmodem-v03029-design.md`

## Global Constraints

- 保持 package version `0.30.29`、tag `v0.30.29` 和 Release 标题 `OpenFinalShell v0.30.29`。
- 裸 `rz` 的本地输入和远端回显必须可见；不得使用旧版 `RzCommandEchoFilter` 隐藏它。
- 此 tag 只产出 Windows x64 安装版和便携版；feed、blockmap 和校验和只能对应 x64 产物。
- SSH 协议识别发生在字符集解码之前；文件内容不整块缓存。
- 对话框取消、解析异常、写入失败和 channel 关闭后清理状态，并保持 SSH 会话可用。

## Review Focus

1. ZMODEM 握手字节跨 SSH chunk 到达；单测覆盖部分 header 缓存和协议帧过滤。
2. 连续 `sz` / `rz` 会话和 parser reset；测试同一 fake channel 上第二次握手仍被处理。
3. `rz` 的可见回显及等待提示符换行；测试终端输入/输出的精确字节。
4. 保存/打开窗口取消及 shell 关闭；测试临时文件清理、普通 shell 输出和二进制数据。
5. x64 tag 资产矩阵；测试工作流条件与资产断言只接受 x64 exe/feed/blockmap。
